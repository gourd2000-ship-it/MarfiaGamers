# 작업 목록: 웹 기반 마피아 게임

## Task 0.1: 학교망 HTTPS/WSS 검증

**수용 기준:**

- [ ] 학교 태블릿에서 HTTPS와 QR URL이 열리고 WSS 이벤트 왕복이 성공한다.
- [ ] 두 브라우저의 WSS 이벤트 왕복이 성공한다.

**검증:** 학교망 태블릿 2대에서 10회 연결을 기록한다.
**의존성:** 없음
**예상 범위:** S

## Task 2.1: 방 URL·QR·로비·자동 기권

**현재 상태:** 코드·Socket 통합 테스트 완료, 학교 태블릿 실기기 검증 대기.

**수용 기준:**

- [x] QR/URL, 닉네임 입장, 4~20명 표준 프리셋, 자동 기권이 동작한다.
- [x] 시작 뒤 신규 입장은 막는다.

**검증:** 다중 브라우저 및 학교 태블릿 수동 테스트.
**의존성:** Task 1.2
**예상 범위:** M

## Task 2.2: 서버 권한 게임 엔진

**현재 상태:** 코드·단위 테스트 완료.

**수용 기준:**

- [x] 서버만 역할·타이머·승패를 확정하고, 의사의 게임당 1회 자기 보호를 검증한다.
- [x] 잘못된 명령은 상태를 바꾸지 못한다.

**검증:** 4·5·6인 역할 조합, 역할 없는 밤 단계 건너뛰기, 타이머·승패 단위 테스트.
**의존성:** Task 2.1
**예상 범위:** M

## Task 2.3: 공개·개인 상태 분리

**현재 상태:** 역할·경찰 조사·기권·서버 기준 카운트다운 공개 상태까지 코드·통합 테스트 완료. 마피아 팀 전용 정보는 후속 보완 대상.

**수용 기준:**

- [x] 역할과 개인 이벤트는 권한 있는 참가자에게만 전송한다.
- [x] 자동 기권한 참가자에게는 개인 상태를 다시 전송하지 않는다.

**검증:** 수신자별 Socket 통합 테스트.
**의존성:** Task 2.2
**예상 범위:** M

## Checkpoint: 공통 기능

- [ ] 6명이 URL로 입장하고 역할 카드를 받는다.
- [ ] 개인 역할 정보 유출 검사가 통과한다.
