# 마피아 게임 UI 디자인 방향 (승인 요청)

> 상태: **승인 전 — 이 문서는 방향 합의용이며, UI 코드는 아직 변경하지 않는다.**

## 참고 자료 확인 결과

요청에 언급된 `doc/` 폴더는 작업 시작 시 레포에 없었다. 따라서 기존 레퍼런스를 해석해 반영할 수 없는 상태다. 레퍼런스 이미지·링크·문서를 `doc/`에 추가하면 승인 전에 색, 레이아웃, 컴포넌트를 그 자료에 맞춰 다시 조정한다.

## 목표

- 가벼운 학교용 도구 느낌 대신, 어두운 마을에서 정체를 추리하는 마피아 게임의 긴장감을 만든다.
- 방 만들기·초대·시작은 처음 쓰는 사용자도 즉시 이해할 만큼 명확하게 유지한다.
- 모바일 세로 화면부터 설계하고, 태블릿에서는 참가자·행동·진행 상태를 한눈에 볼 수 있게 확장한다.

## 시각 언어

| 요소 | 제안 |
| --- | --- |
| 배경 | 거의 검은 남색 `#0B0D14`, 은은한 안개 질감과 매우 낮은 대비의 방사형 빛 |
| 표면 | 차콜 패널 `#171923`, 테두리 `#2B3040`, 종이 질감 대신 유리처럼 얇은 반투명 레이어 |
| 핵심 색 | 위협·경고는 진홍 `#C43B4D`, 시민·확인은 달빛 청록 `#61C7C1`, 본문은 미색 `#F1EEE6` |
| 서체 | 외부 웹폰트 없이 시스템 산세리프를 사용해 학교망에서도 안정적으로 표시 |
| 장식 | 달, 봉인, 카드 모서리, 미세한 노이즈. 공포 이미지나 과도한 깜빡임은 사용하지 않음 |

## 화면 구조

### 모바일 (360~767px)

1. 상단: 게임명, 연결 상태, 현재 단계와 남은 시간
2. 핵심 카드: 내 역할 또는 현재 행동 안내
3. 참가자 목록: 1열 카드, 생존/탈락/기권을 색과 텍스트로 함께 표시
4. 행동 영역: 하단에 고정하지 않고 큰 선택 버튼을 목록 아래 배치
5. 초대 링크·방장 제어: 접을 수 있는 보조 패널

한 손 조작을 기준으로 버튼 높이는 최소 44px, 본문은 최소 16px로 둔다.

### 태블릿 (768px 이상)

```text
┌───────────────────── 상단 상태 바 ─────────────────────┐
│ 게임명 · 연결 상태 · 단계 · 카운트다운                  │
├─────────────┬─────────────────────────┬───────────────┤
│ 참가자      │ 현재 단계 / 역할 / 행동  │ 방 정보·초대   │
│ 목록        │ 투표 결과 / 알림         │ 방장 제어       │
└─────────────┴─────────────────────────┴───────────────┘
```

태블릿에서는 3열, 좁은 태블릿에서는 참가자 목록과 보조 정보를 2열로 재배치한다. 화면 가로 스크롤은 허용하지 않는다.

## 상태별 연출

| 상태 | 색·연출 | 우선 정보 |
| --- | --- | --- |
| 로비 | 차분한 청록 포인트 | 참가자 수, 초대, 시작 가능 여부 |
| 역할 공개 | 역할별 봉인 카드와 짧은 강조 | 본인 역할만 표시 |
| 밤 | 남색·보라 음영, 낮은 움직임 | 역할 행동과 남은 시간 |
| 낮/투표 | 미색 본문과 진홍 선택 강조 | 대상, 투표 결과, 탈락자 |
| 결과 | 승리 진영 색, 재경기·방 종료 | 승리 진영과 다음 행동 |

## 접근성·안정성 기준

- 색만으로 역할·생존·오류를 구분하지 않고 텍스트와 아이콘을 병기한다.
- `prefers-reduced-motion`에서는 안개·카드·타이머 전환 애니메이션을 끈다.
- 키보드 포커스와 명도 대비를 유지한다.
- 외부 이미지·웹폰트 의존성을 두지 않아 제한된 기관망에서도 화면이 열린다.

## 구현 범위 (승인 후)

1. 전역 CSS 토큰과 반응형 그리드 추가
2. 로비·게임 상태·참가자·행동 컴포넌트의 카드형 재구성
3. 역할/투표/결과 상태별 색과 최소한의 모션 적용
4. 모바일 및 태블릿 Playwright 화면 검증 추가
